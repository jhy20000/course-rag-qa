# 课程资料防胡说问答助手

## 项目简介

这是一个最小可运行的本地课程资料问答助手。程序会先从 `course.txt` 中检索和用户问题相关的资料片段，再基于命中的资料生成简短回答。如果资料中没有相关内容，程序会拒绝回答，避免凭空编造。

## 运行方法

在项目目录中运行：

```bash
python main.py
```

启动后在终端输入问题。直接回车或输入 `q` 可以退出程序。

## 功能说明

- 读取本地课程资料 `course.txt`
- 按句号、问号、感叹号和换行切分资料片段
- 从用户问题中提取中文、英文和数字关键词
- 使用关键词命中数量对资料片段排序
- 展示最相关的 3 个资料片段
- 根据命中资料生成模板化回答
- 没有命中资料时输出拒答提示

## 项目和 RAG 的关系

RAG 的核心思路是先检索资料，再根据资料回答问题。本项目用本地文本和关键词匹配实现了一个简化版 RAG 流程，包括资料切分、资料检索、基于资料回答和无依据拒答。

## 当前版本限制

- 只使用关键词匹配，不理解复杂语义
- 没有使用向量数据库
- 没有调用大模型生成自然语言回答
- 只支持单个本地课程资料文件
- 对中文分词的处理比较简单

## 后续升级方向

- 支持多个课程资料文件
- 加入更准确的中文分词
- 使用向量检索提升语义匹配能力
- 增加命中片段高亮展示
- 接入本地或在线大模型生成更自然的回答
- 增加 Web 页面或桌面界面
