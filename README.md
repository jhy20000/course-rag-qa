# 课程资料防胡说问答助手

## 项目简介

这是一个最小可运行的本地课程资料问答助手。程序会先从本地课程资料中检索和用户问题相关的资料片段，再基于命中的资料生成简短回答。如果资料中没有相关内容，程序会拒绝回答，避免凭空编造。

## 运行方法

在项目目录中运行：

```bash
python main.py
```

启动后在终端输入问题。直接回车或输入 `q` 可以退出程序。

## v2.0 升级内容

- 从只能读取单个 `course.txt`，升级为优先读取 `data` 文件夹下的多个 `.txt` 文件
- 每个资料片段都会记录来源文件名
- 命中结果会展示来源文件、命中关键词和资料内容
- 保留资料切分、关键词检索、基于资料回答和无依据拒答
- 保留 `course.txt`，当 `data` 文件夹没有可用资料时可作为旧版回退资料

## data 文件夹说明

`data` 文件夹用于存放课程资料文本。主程序启动时会自动读取 `data` 文件夹下所有 `.txt` 文件，并把每个文件切分成多个资料片段。用户提问后，程序会在这些片段中做关键词匹配，并显示最相关的 3 个结果。

当前示例资料包括：

- `rag_intro.txt`：RAG 基础介绍
- `ai_hallucination.txt`：AI 胡说原因和拒答策略
- `civil_engineering.txt`：结构力学基础介绍

## 运行效果

示例问题：

- RAG 是什么？
- AI 为什么会胡说？
- 什么是结构力学？

运行结果说明：

- `RAG 是什么？` 能够命中 `rag_intro.txt` 中的 RAG 介绍资料。
- `AI 为什么会胡说？` 能够命中 `ai_hallucination.txt` 中的 AI 胡说原因资料。
- `什么是结构力学？` 能够命中 `civil_engineering.txt` 中的结构力学资料。
- 如果问题没有命中任何资料，系统会输出“资料不足，不能根据当前资料回答，避免胡说。”

## 功能说明

- 读取 `data` 文件夹下多个本地课程资料文件
- 按句号、问号、感叹号和换行切分资料片段
- 从用户问题中提取中文、英文和数字关键词
- 使用关键词命中数量对资料片段排序
- 展示最相关的 3 个资料片段
- 显示每个命中片段的来源文件、命中关键词和资料内容
- 根据命中资料生成模板化回答
- 没有命中资料时输出拒答提示

## 项目和 RAG 的关系

RAG 的核心思路是先检索资料，再根据资料回答问题。本项目用本地文本和关键词匹配实现了一个简化版 RAG 流程，包括资料切分、资料检索、基于资料回答和无依据拒答。

## 当前版本限制

- 只使用关键词匹配，不理解复杂语义
- 没有使用向量数据库
- 没有调用大模型生成自然语言回答
- 只支持 `.txt` 文本资料
- 对中文分词的处理比较简单

## 后续升级方向

- 支持 PDF、Word 等更多课程资料格式
- 加入更准确的中文分词
- 使用向量检索提升语义匹配能力
- 增加命中片段高亮展示
- 接入本地或在线大模型生成更自然的回答
- 增加 Web 页面或桌面界面
