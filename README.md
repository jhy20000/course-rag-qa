# 课程资料防胡说问答助手

## 项目简介

这是一个最小可运行的本地课程资料问答助手。程序会先从本地课程资料中检索和用户问题相关的资料片段，再基于命中的资料生成简短回答。如果资料中没有相关内容，程序会拒绝回答，避免凭空编造。

## 运行方法

在项目目录中运行：

```bash
python main.py
```

启动后在终端输入问题。直接回车或输入 `q` 可以退出程序。

## data 文件夹说明

`data` 文件夹用于存放课程资料文本和 Markdown 笔记。主程序启动时会自动读取 `data` 文件夹下所有 `.txt` 和 `.md` 文件，并把每个文件切分成多个资料片段。用户提问后，程序会在这些片段中做关键词匹配，并显示最相关的 3 个结果。

当前示例资料包括：

- `rag_intro.txt`：RAG 基础介绍
- `ai_hallucination.txt`：AI 胡说原因和拒答策略
- `civil_engineering.txt`：结构力学基础介绍
- `study_notes.md`：AI 学习笔记，包含 RAG 核心、AI 幻觉和防止胡说的关键

## 问答记录

程序会把每次用户提问、命中的资料来源和回答结果追加保存到 `history.txt`。如果资料不足，拒答结果也会保存。每条记录之间使用分隔线区分，方便复盘问题和答案依据。

## 功能说明

- 读取 `data` 文件夹下多个本地课程资料文件
- 支持 `.txt` 和 `.md` 两种资料格式
- 按句号、问号、感叹号和换行切分资料片段
- 从用户问题中提取中文、英文和数字关键词
- 使用关键词命中数量对资料片段排序
- 展示最相关的 3 个资料片段
- 显示每个命中片段的来源文件、命中关键词和资料内容
- 根据命中资料生成模板化回答
- 没有命中资料时输出拒答提示
- 自动保存问答记录到 `history.txt`

## 项目和 RAG 的关系

RAG 的核心思路是先检索资料，再根据资料回答问题。本项目用本地文本、Markdown 笔记和关键词匹配实现了一个简化版 RAG 流程，包括资料切分、资料检索、基于资料回答、无依据拒答和问答记录保存。

## 当前版本限制

- 只使用关键词匹配，不理解复杂语义
- 没有使用向量数据库
- 没有调用大模型生成自然语言回答
- 只支持 `.txt` 和 `.md` 文本资料
- 对中文分词的处理比较简单

## 后续升级方向

- 加入更准确的中文分词
